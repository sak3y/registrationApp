# Registration App

An authenticator for a **client project**. Users can **register, log in, and see a welcome screen**. Built with **Java** in **Android Studio**, it stores user data locally using **SharedPreferences** and has a dark-themed UI.

---

## Features

- **User Registration**: Enter username, full name, gender, birth year, and password.  
- **Login System**: Authenticate using locally stored credentials.  
- **Persistent Storage**: User data stored in **SharedPreferences**.  
- **Dark Theme UI**: Clean and student-friendly design.  
- **Dynamic Spinner**: Birth year selection from 1910 to current year.  
- **Welcome Screen**: Displays full user info.  
- **Logout**: Clears session data and returns to login.
